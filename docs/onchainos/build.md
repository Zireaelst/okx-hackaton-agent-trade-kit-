# Geliştirici yolu

OnchainOS'ta iki başlangıç biçimi vardır:

1. **Agent ile:** Resmî Skills/MCP araçlarını kurup doğal dilde görev verin.
2. **Uygulama ile:** Open API dokümanlarından ihtiyacınız olan Wallet, Market, Trade veya Payment arayüzünü seçin.

Bu ayrım [OnchainOS genel bakışında](https://web3.okx.com/onchainos/dev-docs/home/what-is-onchainos) açıklanır. Bir hackathon prototipinde agent yoluyla iş akışını keşfedip daha sonra tekrar edilebilir parçaları API çağrılarına taşıyabilirsiniz.

## Uygulama kontrol listesi

- Zinciri ve token adresini sabit metin adına güvenmeden doğrulayın.
- Okunan her verinin zamanını ve kaynağını gösterin.
- İşlem gerektiren adımları önizleme, onay ve sonuç takibi olarak ayırın.
- Kimlik bilgilerini tarayıcıya veya repoya koymayın; resmi kimlik doğrulama akışını izleyin.

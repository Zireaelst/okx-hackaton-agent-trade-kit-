Build the "ATK Market Data Quality Board" in this repository. Read the current project files and official ATK documentation before changing code: https://github.com/okx/agent-trade-kit and https://github.com/okx/agent-trade-kit/blob/github-main/docs/cli-reference.md. Use the guide at https://okx-tr-atk-hackathon-guide.vercel.app/guide/build/atk-data-quality.

Start from examples/market-quality/ticker.sample.json and examples/market-quality/analyze.mjs. Label fixture prices SIMULATED. Build a small accessible UI showing instrument, source timestamp, data age, bid, ask, spread basis points and explicit warnings for stale, missing, or inverted values. Explain the formula. Keep fixture and live read-only modes visually distinct. If implementing live mode, use only the public OKX TR ATK market ticker command; do not infer missing numbers or ask for API credentials.

Acceptance: fixture produces 200 bps spread and 30,000 ms age; stale data is not presented as current; missing or inverted bid/ask has null spread and a reason; mobile and dark mode remain readable. Run relevant tests and report what was verified. Do not place orders, transfer funds, or connect accounts.
